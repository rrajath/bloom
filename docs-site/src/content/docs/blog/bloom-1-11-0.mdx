Grove has a new name: **Bloom**. It's the same app with the same notes and settings, and there's nothing to migrate. Update as usual from F-Droid, Google Play, or GitHub Releases and you'll keep everything you had.

## Bloom Light and Bloom Dark

1.11.0 adds two new themes, Bloom Light and Bloom Dark. Each one has a matching launcher icon, so with **Sync App Icon with Theme** on, your home-screen icon changes along with the theme. New installs start on Bloom Light, and the Grove Light and Grove Dark themes are still there under their old names.

The default app icon, the Agenda widget's icon, and the Capture widget now use Bloom Light colors too.

See [Themes & Appearance](/features/themes-appearance) for the full list of themes.

## New bloom:// deep links

Links into the app now use the `bloom://` scheme. Existing `grove://` links and pinned shortcuts keep working, so anything you set up before the rename doesn't need to change.
