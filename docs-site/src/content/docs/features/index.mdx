title: Bloom Documentation
description: Feature documentation for Bloom, a native Android org-mode note-taking app.
---

Bloom is a native Android companion for Emacs org-mode users. Every note is a plain `.org` file on disk; Bloom never introduces a proprietary format, and its local index is fully rebuildable from those files at any time.

This section documents every feature currently implemented in the app, one page per feature, with real screenshots from the app itself.

## Install

Bloom is available from three places; pick whichever fits how you manage apps:

- [F-Droid](https://f-droid.org/packages/com.rrajath.grove)
- [Google Play](https://play.google.com/store/apps/details?id=com.rrajath.grove)
- [GitHub Releases](https://github.com/rrajath/bloom/releases): signed APKs attached to every release
