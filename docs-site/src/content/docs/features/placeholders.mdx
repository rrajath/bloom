---
title: Placeholders
description: Template tokens for pulling dates, clipboard content, shared text, and user prompts into a capture template.
---

Capture template bodies support placeholder tokens that get expanded at capture time, the same style of shorthand org-mode users already know from `org-capture-templates`.

## Supported tokens

| Token | Expands to |
|---|---|
| `%t` | Active date, e.g. `<2026-08-01 Sat>` |
| `%T` | Active date+time, e.g. `<2026-08-01 Sat 14:30>` |
| `%u` | Inactive date, e.g. `[2026-08-01 Sat]` |
| `%U` | Inactive date+time, e.g. `[2026-08-01 Sat 14:30]` |
| `%date` | Plain date string |
| `%time` | Plain time string |
| `%day` | Day name |
| `%month` | Month name |
| `%year` | Year |
| `%clipboard` | Current clipboard contents |
| `%shared_text` | Text passed in via the Android share sheet |
| `%shared_url` | The URL from a shared link (see [Share Intake](/features/share-intake)) |
| `%^{prompt}` | Pauses capture and asks the user for input before inserting it: shown as a dialog with the text between the braces as the label |
| `%?` / `%cursor` | Where the cursor lands once the capture editor opens |

## Prompt placeholders

A template using `%^{Title}` shows a dialog asking for "Title" before the capture editor even opens, useful for templates where one piece of information should always be filled in deliberately rather than typed into the body afterward.
