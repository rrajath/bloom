Bloom ships a Glance-based Android app widget for the home screen: a single button that opens the [Capture picker](/features/capture) directly, skipping the app's own navigation entirely.

## Adding the widget

Long-press your home screen, choose **Widgets**, and find Bloom in the list. It's a fixed-size single-purpose widget; there's no configuration screen, since its only job is to open Capture.

## Agenda widget views

Tap the Agenda widget's title (the name with a **▾** next to it) to pick what the widget shows: **Agenda**, or any of your [saved searches](/features/search). Each widget remembers its own choice, so you can put one widget on your agenda and another on a saved search.

A saved search shows its results as one list, in the same order the Search screen lists them, with the result count under the title. Long lists show the first 20 results and a **+N more · view all** row that opens the search in the app. Tapping a task's circle marks it done, the same as on the agenda.

If you rename the saved search, the widget shows the new name. If you delete it, the widget goes back to the agenda.

Tapping the app icon in the widget's top-left corner opens the Agenda screen.

## Agenda widget quick add

The Agenda widget's **+** button opens a small composer over whatever app you're in: a keyword chip, the task text, and date and priority chips. The task goes to the **quick add target**, shown as a label next to the chips (for example `tasks › Work › Inbox`). Tapping outside the composer closes it; taps inside it, including on the target label, keep it open.

Set the target in **Settings › Widget › Quick add target**. Pick a file to add tasks at the bottom of it, or drill into a heading to add them as its last child. Until you pick one, quick add uses the share target from **Settings › Sharing**, so links shared from a browser and quick tasks can live in different files.

If the target heading is renamed or deleted, the task is added to the bottom of the file instead and a message says so.
