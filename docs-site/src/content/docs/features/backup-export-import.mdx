Settings → Backup covers Bloom's own configuration, not your notes. Your `.org` files are already durable, plain-text, and synced independently (see [Sync](/features/sync)); this screen is for everything else: preferences, capture templates, favorites and saved searches.

## Automatic backup

Turn on **Back up automatically** and pick a folder. Bloom then keeps one file in that folder, `bloom-settings.json`, up to date on its own: about 2 seconds after you change a setting, a capture template, a favorite or a saved search, it rewrites the file. It holds the same sections as a manual export. Nothing runs in the background when nothing changes, and a change that leaves the file's contents the same doesn't rewrite it.

Pick a folder your sync tool already covers (Syncthing, Nextcloud and so on) and the backup travels off the device with no extra steps. Bloom overwrites the one file in place; it doesn't keep older copies.

- **Backup folder** shows the chosen folder's full path. Tap it to pick a different one. Picking a folder writes the file right away.
- If the folder already holds a backup that doesn't match this device (say, on a new phone, or after reinstalling Bloom), nothing is written until you choose: **Restore** brings that backup onto this device (backups start once you confirm the import), **Replace** overwrites it with this device's settings, and **Cancel** leaves both the file and the switch as they were.
- The status line under it says when the file was last written. If the file goes missing (deleted in a file manager, for example), Bloom writes it again the next time it starts or you open this screen. If Bloom can no longer write there (the folder was deleted or its access was revoked), it says so in red; tap it to choose the folder again.
- **Restore from automatic backup** reads the file and opens the same section checklist as [Import](#import). It's available once the file exists.
- Turning the switch off stops the writes but remembers the folder and leaves the file where it is. While off, the folder, status and Restore are shown greyed out.

If two devices back up into the same synced folder, the last one to write wins: the file mirrors one device, it doesn't merge them. Give each device its own folder if you want separate backups.

Like the sync folder, the backup folder and its status stay on this device and aren't part of the backup file.

## Export

The **Manual** group works on a file you choose each time. Tap **Export** to write one JSON file, named `bloom-backup.json` by default, with:

- **Settings**: every preference on the Settings pages, such as theme, text sizes, TODO keywords, sync mode, Agenda swipe actions, reminders, sharing and attachment defaults.
- **Capture templates**: every template, in order.
- **Favorites**: your favorite notes, in order.
- **Saved searches and Quick Start cards**: your saved searches plus any Quick Start card you've customized from the search screen.

The sync folder isn't included. A folder permission can't move to another device, so it stays as it is on this one.

The file carries a schema version (currently 18). Older exports still import cleanly: settings they predate fall back to their defaults, and an export made before templates, favorites and saved searches were included simply has no such sections.

## Import

Tap **Import** and pick a previously exported file. If it holds only settings (an older export), Bloom applies them straight away. Otherwise a dialog lists each section the file contains, with counts, all checked to start. Uncheck anything you want to keep as it is, then tap **Import**.

Each checked section **replaces** what's on this device. For example, importing capture templates swaps your current templates for the ones in the file; it doesn't merge them. Favorites point at notes by file path and heading ID, so they work best when the vault on this device has the same files.

Because this covers every settings surface, any time a new setting is added anywhere in the app, the export/import logic is updated to include it, so a backup stays complete going forward.
