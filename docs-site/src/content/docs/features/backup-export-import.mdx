Settings → Backup covers Bloom's own configuration, not your notes. Your `.org` files are already durable, plain-text, and synced independently (see [Sync](/features/sync)); this screen is for everything else: preferences, capture templates, favorites and saved searches.

## Export

Tap **Export** to write one JSON file, named `bloom-backup.json` by default, with:

- **Settings**: every preference on the Settings pages, such as theme, text sizes, TODO keywords, sync mode, Agenda swipe actions, reminders, sharing and attachment defaults.
- **Capture templates**: every template, in order.
- **Favorites**: your favorite notes, in order.
- **Saved searches and Quick Start cards**: your saved searches plus any Quick Start card you've customized from the search screen.

The sync folder isn't included. A folder permission can't move to another device, so it stays as it is on this one.

The file carries a schema version (currently 17). Older exports still import cleanly: settings they predate fall back to their defaults, and an export made before templates, favorites and saved searches were included simply has no such sections.

## Import

Tap **Import** and pick a previously exported file. If it holds only settings (an older export), Bloom applies them straight away. Otherwise a dialog lists each section the file contains, with counts, all checked to start. Uncheck anything you want to keep as it is, then tap **Import**.

Each checked section **replaces** what's on this device. For example, importing capture templates swaps your current templates for the ones in the file; it doesn't merge them. Favorites point at notes by file path and heading ID, so they work best when the vault on this device has the same files.

Because this covers every settings surface, any time a new setting is added anywhere in the app, the export/import logic is updated to include it, so a backup stays complete going forward.
