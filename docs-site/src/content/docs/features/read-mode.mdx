## What's rendered

Bloom parses the note's org markup and renders it through a custom `AnnotatedString`-based renderer; there is no WebView involved. Supported inline styles:

- **Bold**, *italic*, underline, `code`
- Links (`[[target][description]]`)
- Checklists (`- [ ]` / `- [-]` / `- [X]`)
- Planning-date chips: SCHEDULED shown with a calendar icon, DEADLINE with a flag icon, and a violet `●` chip for each bare active `<date>` event on the heading, and a muted check chip for the CLOSED date of a done heading
- Tag pills, TODO/keyword chip, and priority tag at the top
- Collapsible drawers (`:LOGBOOK:`, `:PROPERTIES:`): tap to expand

## Checklists

Checklist boxes are interactive in Read mode:

- **Tap** a box to toggle it done. An empty or in-progress box becomes `[X]`; a done box goes back to `[ ]`.
- **Tap and hold** a box (with a short haptic buzz) to mark it in-progress `[-]`. Hold again to clear it back to `[ ]`.

Toggling a box also refreshes its parent's statistics cookie (`[1/3]`, `[50%]`) and, when the parent is itself a checkbox, checks or unchecks it to match whether all its children are done. The file on disk is updated and synced on each change.

## Following links

Tap a `[[target][description]]` link to jump to what it points at:

- A heading link (`[[id:...]]`, `[[#custom-id]]`, `[[*Heading]]`, `[[file:other.org::*Heading]]`) opens that heading in Read mode.
- A whole-file link opens that file's [Outline View](/features/outline-view). This includes an `[[id:...]]` link whose id matches a file-level `:ID:` (one in the property drawer above the first heading), not a heading.
- An external link (`https:`, `mailto:`, `tel:`, ...) is handed to the system.
- A [Denote](https://protesilaos.com/emacs/denote) link (`[[denote:20240101T120000]]`) opens the outline of the file whose name carries that identifier, wherever it is in the vault. Add `::*Heading` or `::#custom-id` to open a heading inside it.

Id and custom-id links resolve across the whole vault from the rebuildable index, so they keep working after the target file is renamed or moved. If nothing matches, Bloom shows a brief "Couldn't find" message instead of navigating.

## Breadcrumbs

Above the title, a breadcrumb trail (`tasks › Finish Q3 roadmap deck`) shows the notebook and heading path. Tapping the notebook name jumps back to Outline View, narrowed to this note's position.

## Top bar

- **← Back**: returns to Outline View
- **Read / Edit** segmented toggle: switches instantly between Read and Edit mode with no navigation transition or backstack entry

A floating **☰** button at the bottom-right opens the [Metadata bottom sheet](/features/metadata-sheet).

## The whole file as one note

Read mode normally shows one heading and its subtree. The Outline's **View file** (and, for an org-roam file with the "Open roam files directly in read mode" setting on, opening a small notebook at all) shows the entire file instead: the preface, the intro and every heading in one scroll, rendered exactly like a note, with headings foldable and the same Read/Edit toggle. The header shows the file name as a breadcrumb, same style as the notebook/heading trail above — tap it for the outline — and there is no ☰ button, since its actions belong to a single heading. A file nested two or more folders deep shows each folder's first letter only (`work/ideas/app.org` → `w/i/app.org`), and a long name wraps onto a second line rather than getting cut off. Edit mode there is the whole file in one editor, with the same wrapping, folder-compacted file name below the top bar. Switching back to Read, with the toggle or Back, never saves: Read shows your unsaved text until you tap the green save icon, and leaving the file asks whether to save or discard. For an org-roam file, the Backlinks bar (see [Settings](/features/settings-overview#roam-features-experimental)) shows at the bottom of both. See [Outline View](/features/outline-view#viewing-the-whole-file) for the line limit that keeps this off for very large files.

## Favoriting

Tap the star in the metadata area (or use the swipe action from Outline View) to favorite a note. Favorited notes appear in the navigation drawer for one-tap access.

If the heading has no `ID` or `CUSTOM_ID` yet, favoriting adds an `ID` property so the favorite keeps pointing at the right heading after edits move it.
