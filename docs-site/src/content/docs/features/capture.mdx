Capture is Bloom's fast path for adding a note without navigating into a notebook first. Pick a template, fill in the blanks (if any), and Bloom writes the entry to the right file and location automatically.

## Capture picker

Each row shows the template name, its target file, and where new entries are inserted (top of file, bottom of file, under a heading, or into a datetree). Tapping a template either opens the capture editor directly, or (if the template has a `%^{prompt}` placeholder) first asks for that input:

![A "Title" prompt dialog with a text field and Cancel/Continue buttons, triggered by opening a template that uses a %^{prompt} placeholder](../assets/capture-title-prompt.png)

**Manage** jumps to [Capture Templates](/features/capture-templates) to add, edit, or reorder templates.

## Capture editor

The editor is pre-filled with the template's expanded content, including any datetree breadcrumb path that was just auto-created:

<ThemeShot
  light={captureEditorLight}
  dark={captureEditorDark}
  alt='Capture editor for "Journal Entry" showing the auto-created datetree breadcrumb journal.org › 2026 › October › Mon 19, a blank heading with an inline timestamp, and a Save button'
  widths={[340, 680]}
  sizes="340px"
/>

A bar above the editor always shows where the entry will land, so you know before you save:

- **Top / bottom of file**: the file name, with a `top of file` or `bottom of file` pill.
- **Under a heading**: the file plus the target heading's full outline path (for example `inbox.org › Projects › Work › Meetings`), with a pill for where it goes: `first child`, `last child`, or `under heading` for templates that add text to the heading itself. If the heading can't be found, the pill turns red and reads `not found`. Long paths are shortened in the middle so the file and the target heading both stay visible.
- **Datetree**: the file, the heading the tree grows inside (if any), and the date chain (Year › Month › Day, Year › Week › Day, or Year › Month), with an `auto-created` pill. If the heading can't be found, the pill turns red and reads `not found`.
- **Roam node**: the new file's path, updating as you type the title, with a `new file` pill (or `existing` when the title matches a file that's already there).

The heading you're writing is never part of the path; the bar only shows what it will sit under.

It's the same `BasicTextField` editor and [formatting toolbar](/features/edit-mode) used for regular note editing: bold/italic/underline/code, checkbox and link insertion, timestamp insertion. **Save** splices the finished entry into the template's configured target location; the **×** in the top-left discards it (with a confirmation if you've typed real content).

## Entry points

Capture is reachable from more places than any other Bloom screen:

- The **Capture** FAB on the Notebooks screen
- The [home-screen widget](/features/widget)
- The Android **share sheet** (see [Share Intake](/features/share-intake))
- An optional **ongoing notification** (toggle in Settings → Capture Templates)
- The `bloom://capture` deep link, including long-press launcher shortcuts
